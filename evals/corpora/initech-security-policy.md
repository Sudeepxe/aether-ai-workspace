# Initech Security Policy

## Authentication

Initech requires two-factor authentication (2FA) for all employee
accounts with access to production systems. 2FA must use an
authenticator app; SMS-based codes are not accepted as the second
factor.

## Password requirements

Passwords must be at least 14 characters and are rotated every 180
days. Password reuse across the last 10 passwords is blocked by the
identity provider.
