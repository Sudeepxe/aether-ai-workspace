# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to **sudeepc380@gmail.com**
with subject `[SECURITY] aether-ai-workspace`. You will receive an
acknowledgement within 72 hours.

Please do not open public issues for security reports.

## Disclosure

Coordinated disclosure with a 90-day window (see Blueprint §9.4). Credit is
given in release notes unless you prefer otherwise.

## Scope notes

The published known-gaps register (Blueprint §10.6) lists deliberate v1
limitations (e.g., MFA deferred to Phase 3). Reports confirming a registered
gap are welcome but will be triaged as roadmap items, not incidents.
