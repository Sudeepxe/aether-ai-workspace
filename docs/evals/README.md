`evals/harness/cli.py` (Sprint 7) against real infrastructure: real

regression.

correct-refusal ≥ 90% both need a real generator judged by a real
cross-family LLM — this environment has no OpenAI/Anthropic key

retrieval hit-rate, citation precision, and citation recall are all
100% against the v1 golden set. See the report for the full breakdown
and the tracked, explicit list of what's still a gap.
