# Architecture

`blueprint.md` is the frozen, approved architecture blueprint (signed off —
see Chapter 11). It is split per chapter below for navigability; each
chapter carries a **status-vs-implementation header** updated per sprint
(Ch. 9 F-4), so design/reality drift is visible and dated.

Changes to any accepted decision require a superseding ADR (`docs/adr/`),
never an edit to the frozen text.
